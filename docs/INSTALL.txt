E note 安装与使用
================

系统要求：macOS 13 或更高版本，支持 Intel 和 Apple 芯片。
不需要安装 Xcode、Python 或命令行工具。不登录也能使用本机便签和待办。
不支持 Windows、iPhone 或 iPad。

官方下载
https://github.com/itxd/E-note/releases/latest
选择 E-note-macOS-universal.dmg，不要下载 Source code。

安装步骤
1. 双击下载的 DMG 文件。
2. 将 E note 拖到旁边的 Applications（应用程序）文件夹。
3. 在“应用程序”中双击 E note，完成后可推出安装磁盘。
4. 把鼠标移到屏幕边缘的小条，即可展开便签。此应用不显示 Dock 图标。
5. 第一张是待办清单；按 Option + Command + N 新建普通便签。
   右键屏幕边缘小条可打开设置或退出。

首次打开提示无法验证开发者
此版本使用本机临时签名，尚未使用 Apple Developer ID 签名或经过 Apple 公证。
如果你确认安装包来自上面的官方仓库且未被篡改：
尝试打开一次后，在“系统设置 → 隐私与安全性”中点击“仍要打开”，
再按系统提示确认。以后通常可直接打开。
Apple 官方说明：https://support.apple.com/zh-cn/102445
如果系统明确提示“将损坏你的电脑”或文件损坏，请停止安装并反馈。

更新与卸载
1.0.3 起默认每天检查新版本，也可在边缘小条右键菜单或“设置 → 关于”点击“检查更新”。
发现新版后点击“一键更新并重启”，下载并验签成功后保存全部便签、安装并重启。
保存或更新前备份失败时会停止升级；设置中可关闭自动检查。
1.0.2 及更早版本需手动安装一次：从边缘小条右键菜单退出旧版，再将新版拖入“应用程序”替换。
卸载时退出应用，将“应用程序”中的 E note 移到废纸篓。
便签数据保留在 ~/Library/Application Support/ENote/，以便以后恢复。
