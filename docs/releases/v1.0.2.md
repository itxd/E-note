# E note v1.0.2

适用于 macOS 13+，同一安装包支持 Intel 与 Apple 芯片。

## 下载和更新

下载 **E-note-macOS-universal.dmg**，退出正在运行的旧版 E note，再把新版拖到 Applications 并替换。现有便签数据会保留。

本版本采用临时签名，尚未经过 Apple Developer ID 签名和公证。首次打开提示无法验证开发者时，请参阅随包安装说明。

## 更新内容（相对于 v1.0.0）

- 优化便签库待办输入：草稿更新不再触发整张列表重新计算和解密。
- 双击悬浮便签侧边标签，将宽高放大至原来的 2.5 倍；再次双击还原，尺寸受屏幕可用范围限制。
- 待办增加创建／查看关联便签按钮；重复点击复用同一便签，支持恢复已归档或软删除的关联便签。
- 关联便签显示 T000001 格式的任务编号，内部使用稳定 UUID 关联；同步冲突副本保留正文但解除重复关联。
- TODOList 更名为“待办清单”，新增时间、重要程度及标题快捷操作，仅允许删除已完成或已归档待办。
- MCP 提供 19 个本机工具，支持便签、待办、标签操作；本地 API 升级至 v2。安装方法见仓库 docs/MCP.md。

## 验证及范围

已通过原生 UI 输入、缩放还原、关联便签复用、HTTP/MCP 联调、云端事务与双设备同步测试；安装包包含 x86_64 和 arm64，已验证签名。运行测试在 Intel Mac 上完成，未在 Apple 芯片实机验证。

源码同时包含云端工作流复用已有便签的改动；升级桌面安装包不会自动更新服务端，服务端需单独部署。
